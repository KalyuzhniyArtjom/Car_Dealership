# repart
Car Dealership — старт разработки веб-приложения для автосалона. Проект только начинается, в планах — создать удобный инструмент, где покупатели смогут просматривать автомобили, а менеджеры — управлять каталогом и продажами. Сейчас ведётся работа над структурой базы данных и базовым интерфейсом, постепенно функционал будет расширяться. Репозиторий буду обновлять по мере продвижения.
